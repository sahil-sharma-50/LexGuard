# Documentation index

Use README.md for the shortest path from a fresh clone to a local
installation. The documents below provide deeper operational, research, and
submission context.

## Project and design

- PRODUCT.md: product purpose, users, capabilities, constraints, and
  accessibility requirements.
- DESIGN.md: visual language, layout rules, typography, and interaction
  principles.
- FINDINGS.md: verified Alpaca integration notes and research references.
- hackathon-description.md: working summary of the event requirements used
  during development. Confirm current rules on the official event page.

## Running and deploying

- runbook.md: paper account setup, readiness gates, operator controls,
  scheduler operation, and evidence export.
- ../infra/DEPLOY.md: Railway and Vercel topology, environment variables, and
  post-deployment checks.

## Research

- research/methodology.md: dataset boundaries, simulation rules, fee model,
  research gates, and artifact integrity.
- research/paper-forward-report.md: operator-owned paper-forward evidence
  gate. It remains incomplete until reconciled evidence exists.

## Submission

- submission/one-page-writeup.md: concise project explanation.
- submission/demo-script.md: live demonstration outline.
- submission/slide-outline.md: presentation structure.
- submission/claim-evidence-map.md: claim provenance and reproduction commands.
- submission/lablab-draft.md: submission copy with placeholders for final
  links, account details, and evidence.

Do not add private account IDs, API responses, credentials, or unreconciled
performance claims to these files.
